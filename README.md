# Pixel Life Android

A native Android starter project for the Pixel Life glow-up RPG.

## Included
- White, minimal retro-game inspired interface
- Daily quests with red unfinished / green completed states
- XP scoring capped at 20 per day
- 7-day calendar with selectable days
- Character hydration and hygiene states
- Four custom bonus quests
- Four-slot hobbies board
- Weekly XP bars and achievement badges
- Progress stored locally with Android SharedPreferences

## Build an APK
1. Install Android Studio on a computer.
2. Open this `PixelLifeAndroid` folder in Android Studio.
3. Allow Gradle sync and install the Android SDK platform 35 if prompted.
4. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Android Studio will show the generated APK location, usually `app/build/outputs/apk/debug/app-debug.apk`.

This source project has not been compiled in this environment. A working Android SDK/Gradle build setup is required to produce the installable APK.
